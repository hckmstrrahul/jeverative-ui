# Project preferences

Jeverative runs locally with `npm run dev`. The user has authorized a private GitHub repository at `hckmstrrahul/jeverative-ui` and Vercel hosting at `jeverative-ui.vercel.app`.

Do not publish to ChatGPT Sites. Deploy to Vercel only when requested. Keep session keys, `.env` files, local benchmark captures and deployment credentials out of Git. The public deployment uses visitor-supplied OpenRouter keys; do not provision a shared billable key without explicit authorization.
